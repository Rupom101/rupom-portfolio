# Rupom Ahmed Portfolio

Complete static portfolio for GitHub Pages.

## Files

- `index.html` — complete page structure and content
- `style.css` — complete responsive design, animations and theme styles
- `script.js` — mobile menu, dark/light mode, scroll progress, project filters, project modal and reveal animations
- `rupom.jpg` — keep your existing profile photo in the same folder

## Deploy to GitHub Pages

Upload/replace these files in the repository:

`Rupom101/rupom-portfolio`

The site URL remains:

`https://rupom101.github.io/rupom-portfolio/`

No extra snippets or separate code additions are required.

## Important

Keep the existing `rupom.jpg` file beside `index.html`. The portfolio uses that filename for the profile image.
